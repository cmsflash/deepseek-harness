# @deepseek-ai/dsh-client-ui-focus

[English](README.md) | 中文

Focus 会话视图（浏览器端部分）：一个纯增量的 `conversation.view` 条目（id `focus`，order 5），在折叠的逐轮指标行之上完整渲染最新一轮。它的用途是阅读长会话而不必滚过已结束的工具调用：更早的每一轮都收敛成一行，携带该轮的步数与调用次数、增删行数、涉及文件数、耗时与 token 消耗，其后是一行汇总。当前轮保留其发起消息、助手正文、推理内容与全部工具调用——包括仍在进行的调用，因此纯工具轮从第一帧起即可见，无需等它结束。下一轮开始时，此前完整渲染的那一轮会折叠为又一行指标。

该视图自行从与目标无关的 `ConversationNode` 流以及引擎持有的轮次时间线派生全部数字，两者均经 `useSession` 读取。它不注册 Conversation Definition，也不发布 Location 数据，因为它并未引入新的业务事件族：本插件只是 Chat Definition 已装配结果的第二个读者。轮次归属遵循日志顺序——工具结果归属于其前方最近一个助手步所在的轮次——最新一轮的切片从该轮自身的 `turn/start` 开始，因此边界来自引擎而非推断。增删行数取自 write 与 edit 工具返回的已应用 `card:'diff'` 结果视图；由于这些视图跨进程传输且只有 `card` 字段经过 schema 校验，折叠会逐条校验并跳过畸形条目，而不是在渲染中抛错。

Chat 不受影响：`conversation.chat.node` 由 chat 视图条目声明因而由其占有，所以本插件渲染自有行，不去分派其它视图的 keyed renderer；从 bundle 中移除 `ui-focus` 行即可去掉该标签页，对既有转录毫无影响。

`/client` 导出为插件主体（`apply`/`inject`）、`FocusView` 组件及其注入面类型，以及视图所依赖的纯折叠函数。

## 组合

```yaml
- id: ui-focus
  name: '@deepseek-ai/dsh-client-ui-focus'
```

注入 `slots`（视图环）、`sessions`（常规历史分页）与 `locale`。标签文案以 thunk 形式经绑定的 translate 读取，因此随激活语言变化而无需重新注册。

## Model Experience

无，因为本插件只把已记录的会话事件折叠为浏览器端读模型：不发起请求、不写入会话事件，也不贡献任何 prompt、工具 schema 或工具结果，因此当前激活哪个视图标签页都不会改变模型所收到的内容。

#### KV Cache 影响

无；本插件从不装配或发送 provider 请求。

## 已知限制与后续工作

- **数字以窗口为范围，而非整个日志** — 已加载的历史窗口是分页的，因此汇总描述的是当前已加载的轮次。当更早历史尚未加载时，指标带会显示明确提示与分页控件；`turn/start` 落在窗口之外的轮次不报告耗时。逐轮归属没有可依赖的持久投影：`sessionStats` 与 `tokenUsage` 都是整会话总量，逐轮等价物需要新的 host 侧投影单元。
- **没有单轮成本** — harness 中不存在任何模型定价，且 provider 适配器把线上 usage 映射为仅含 token 的 `TokenUsage`（`llm-deepseek` 的 `mapUsage`），而 `llm-pi-ai` 明确将目录中的 `ModelCost` 归零，因此端点上报的花费从不会到达客户端。展示成本需先有价格来源；这些行显示 token 计数，而不臆造费率。
- **增删行数只覆盖 diff 卡片类工具** — 由不返回 `card:'diff'` 结果视图的工具（shell 的 `sed`、某个脚本）所做的改动不计入行数；该计数是对整份前后镜像做的行多重集差分，因此移动的行读作未变，修改的行读作一增一删。
- **汇总行中的涉及文件数为逐轮相加** — 跨多轮编辑的同一文件在汇总行中按轮各计一次；逐轮行本身仍然精确。
- **最新一轮渲染的是简化转录** — 包含正文、推理、终端卡片与原始参数，但不含 chat 视图注册的 renderer 所提供的完整 keyed 工具卡片、图片与逐消息操作。当某个调用需要其富卡片时，请切回 Chat 标签页。
